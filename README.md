## About the Project

## Run Locally

### Prerequisites

- Node.js
- npm

### Installation

1. Install dependencies:

   `npm install`

2. Set your `GEMINI_API_KEY` in the `.env.local` file if the application requires it.

3. Start the development server:

   `npm run dev`

4. Open the local URL displayed in your terminal.
